Socket/1.1 deals in bytes, Wisp in words, Pit Wall in meaning. In each one I wrote the part most projects import, so I would know how it works when it breaks.

Socket/1.1

An HTTP/1.1 server written on raw TCP sockets

It reads bytes from Node's net module and parses them with its own state machine, without touching node:http. A compatibility layer runs an unmodified Express app on top, and it rejects the conflicting framing headers behind request smuggling.

Pit Wall

An F1 rulebook assistant that cites the exact article

Ask about the FIA Sporting Regulations and it answers from the five clauses closest to your question, citing each one, like Art. B5.14.2. Every citation is checked in code against what was retrieved, and any that fails is struck out on screen.
